## Contributors

*This section will be updated as the community grows. If you've contributed, please add yourself in a pull request!*

## Contribution Types

We recognize the following types of contributions:

- **Code**: Bug fixes, new features, performance improvements
- **Documentation**: README updates, tutorials, examples
- **Domain Expertise**: Validation rules, workflow templates, scientific correctness review
- **Testing**: Bug reports, test cases, compatibility testing
- **Community**: Answering questions, mentoring newcomers, organizing events

## Recognition

Contributors will be:
- Listed in this file
- Mentioned in release notes for significant contributions
- Invited to join the core team after sustained contribution
