## Add ai4s-core to Awesome Scientific Computing

**Name**: ai4s-core
**Link**: https://github.com/agent2agent-dev/ai4s-core
**Description**: Natural language interface for scientific computing workflows. Translates plain English into validated, executable pipelines for molecular dynamics, DFT, quantum chemistry, bioinformatics, and materials simulation.

**Why it fits this list:**
ai4s-core bridges the gap between natural language and scientific computing tools. It generates validated workflow scripts for GROMACS, Quantum ESPRESSO, ORCA, LAMMPS, and more — with domain-specific validation rules that catch errors before compute time is wasted.

**Key features:**
- 5 scientific domains: MD, DFT, Quantum Chemistry, Bioinformatics, Materials Simulation
- Domain-specific validation engine (temperature ranges, force field compatibility, DFT cutoff checks)
- Local LLM support (llama.cpp, Ollama, vLLM) — no data leaves your machine
- Execution engine with Docker + local subprocess support
- MIT license, 44 tests passing
