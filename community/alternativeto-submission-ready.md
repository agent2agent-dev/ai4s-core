- Natural language to executable workflow
- Scientific correctness validation engine
- Local LLM support (privacy-friendly)
- 5 scientific domains: MD, DFT, Bioinformatics, Quantum Chemistry, Materials Simulation
- Mock mode for zero-dependency demo
- CLI interface
